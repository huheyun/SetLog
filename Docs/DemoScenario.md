# SetLogPlus 3분 이내 시연 영상 시나리오

## 시연 목표

SetLogPlus가 "그룹 기반 짧은 영상 일상 기록 앱"이라는 점을 3분 안에 보여준다. 핵심은 로그인, 그룹, 카메라 촬영, 업로드, 그룹 피드, 영상 상세 보기, 소리 재생, 이모지 반응, 프로필 흐름이다.

## 준비 사항

- 테스트 계정 1개 이상 준비
- 테스트 그룹 1개 준비
- 가능하면 그룹에 멤버 2명 이상 준비
- 업로드 지연에 대비해 네트워크 상태 확인
- 시연 전에 짧은 테스트 영상을 한 번 올려서 피드가 비어 있지 않게 준비

## 전체 시나리오

### 0:00-0:20 앱 소개 및 로그인

화면:
- 앱 실행
- 로그인 화면
- 테스트 계정으로 로그인

대본:
"SetLogPlus는 Setlog에서 영감을 받은 짧은 영상 일상 기록 앱입니다. 인스타그램 같은 큰 SNS보다는, 가까운 그룹 안에서 아주 짧은 영상을 올리고 가볍게 확인하는 데 집중했습니다."

### 0:20-0:45 홈 화면과 그룹

화면:
- 홈 화면
- 그룹 목록
- 그룹 생성 또는 기존 그룹 확인
- 그룹 클릭 후 그룹 피드 진입

대본:
"로그인하면 내가 속한 그룹 목록을 볼 수 있습니다. 사용자는 새 그룹을 만들 수 있고, 초대 코드를 통해 다른 사람의 그룹에 참여할 수도 있습니다. 그룹을 누르면 해당 그룹의 로그 피드로 이동합니다."

### 0:45-1:25 카메라 촬영

화면:
- 하단 카메라 버튼 클릭
- 카메라 화면
- 배율, 플래시, 카메라 전환 버튼 짧게 보여주기
- 3초 영상 촬영
- 촬영 진행 바 보여주기

대본:
"SetLogPlus의 핵심은 사진첩에서 영상을 고르는 것이 아니라, 지금 바로 짧게 촬영해서 올리는 것입니다. 영상은 약 3초 정도로 제한했고, 촬영 중에는 진행 바를 통해 남은 시간을 알 수 있습니다."

### 1:25-1:55 업로드 그룹 선택

화면:
- 촬영 후 업로드 화면
- 영상 미리보기
- 보낼 그룹 선택
- 소리 포함/무음 토글
- 업로드 버튼 클릭

대본:
"촬영이 끝나면 이 영상을 어떤 그룹에 올릴지 선택할 수 있습니다. 여러 그룹에 한 번에 올릴 수도 있고, 업로드 전에 소리 포함 여부도 선택할 수 있습니다."

### 1:55-2:30 그룹 피드와 영상 상세

화면:
- 그룹 피드로 이동
- 멤버별 영상 카드 확인
- 시간 dot 확인
- 영상 카드 탭 또는 롱프레스
- 상세 화면에서 영상 크게 보기
- 소리 버튼 토글

대본:
"그룹 피드에서는 선택된 시간대에 멤버별로 올라온 영상을 확인할 수 있습니다. 영상이 올라온 시간대만 이동할 수 있게 해서 불필요한 빈 화면을 줄였습니다. 영상을 열면 더 큰 화면으로 볼 수 있고, 소리도 명확하게 들을 수 있습니다."

### 2:30-2:50 이모지 반응

화면:
- 피드 또는 상세 화면에서 반응 버튼 클릭
- 이모지 선택
- 카드에 반응 요약 표시 확인
- 같은 이모지를 다시 눌러 취소 가능하다는 점 보여주기

대본:
"MVP에서는 채팅 대신 이모지 반응을 사용했습니다. 채팅은 기능이 무거워질 수 있기 때문에, 짧은 로그 앱의 성격에 맞게 좋아요와 비슷한 가벼운 반응으로 대체했습니다."

### 2:50-3:00 프로필 및 마무리

화면:
- 프로필 화면
- 닉네임 변경 위치
- 내가 속한 그룹 목록
- 로그아웃 위치

대본:
"프로필에서는 닉네임을 수정할 수 있고, 내가 속한 그룹 목록과 로그아웃 기능을 확인할 수 있습니다. SetLogPlus의 MVP는 로그인부터 촬영, 업로드, 피드 확인, 상세 보기, 반응까지 짧은 영상 기록의 전체 흐름을 구현했습니다."

## 촬영 팁

- 영상 업로드 대기 시간이 길어지면 그 부분은 편집으로 줄인다.
- 설명보다 실제 화면 조작을 중심으로 보여준다.
- 3분 제한이 있으므로 그룹 설정 화면은 길게 보여주지 않는다.
- 채팅 기능은 제외했고 이모지 반응으로 대체했다는 점을 짧게 설명한다.
